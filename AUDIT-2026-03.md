# Toranot Repository Audit — March 2026

Comprehensive audit of all branches, files, configurations, security, performance, and architecture with actionable improvements.

---

## Executive Summary

**Toranot** is a hospital ward shift management PWA (Hebrew: "תורנות") for on-call doctors in geriatrics/internal medicine. It provides patient tracking, task automation, drug safety alerts, lab trend monitoring, OCR scanning, AI clinical reasoning, and cloud sync.

**Tech Stack**: React 19 + TypeScript + Zustand + Tailwind CSS v4 + Vite 7 + Netlify Functions + Supabase

**Overall Assessment**: Well-architected medical PWA with strong security practices, comprehensive test suite (826 tests across 24 files), and thoughtful clinical safety features. Several security hardening opportunities and code quality improvements identified and fixed.

## Remaining Issues & Recommendations

### High Priority (Should Fix Soon)

#### 1. API Key Storage in localStorage
- **File**: `src/components/OverflowMenu.tsx`, `src/components/Scanner.tsx`
- **Issue**: Anthropic API key stored unencrypted in `localStorage` as a fallback
- **Risk**: Vulnerable to XSS, browser extensions, third-party scripts
- **Recommendation**: Make the server-side proxy mandatory for production; allow direct API key only in dev mode via environment variable

#### 2. XSS Risk in AI Output Rendering
- **File**: `src/components/AIClinicalReasoning.tsx`
- **Issue**: Uses `dangerouslySetInnerHTML` with regex-transformed markdown
- **Mitigation**: DOMPurify is used, but regex replacements after sanitization could introduce bypass vectors
- **Recommendation**: Use a proper markdown-to-React renderer (e.g., `react-markdown`) instead of innerHTML

#### 3. PatientCard.tsx is Too Large
- **File**: `src/components/PatientCard.tsx` (~1500+ lines)
- **Recommendation**: Extract sub-components: `TaskSection`, `LabBadges`, `SafetyAlerts`, `PhotoSection`

#### 4. Missing Error Boundaries
- **Issue**: Only the top-level `AppErrorBoundary` exists
- **Recommendation**: Add error boundaries around Scanner, AIClinicalReasoning, HandoffSheet — these are the most crash-prone features

### Medium Priority

#### 5. Memory Leak Risk in Timer Components
- **Files**: `TaskCountdown.tsx`, `Scanner.tsx`, `QuickReference.tsx`
- **Issue**: `setTimeout` calls not always cleaned up on unmount
- **Recommendation**: Store timeout IDs in refs and clear in cleanup functions

#### 6. Missing `React.memo` on Expensive Components
- **Files**: `DrugSafetyAlerts.tsx`, `IVProtocolAlerts.tsx`, `MedFlags.tsx`, `LabChart.tsx`
- **Issue**: These re-render on every parent render even when props haven't changed
- **Recommendation**: Wrap with `React.memo()` for better performance with 50+ patients

#### 7. Missing Accessibility
- **Issue**: Many icon-only buttons lack `aria-label` attributes
- **Files**: `TaskItem.tsx`, `OverflowMenu.tsx`, `PatientCard.tsx`
- **Recommendation**: Add `aria-label` to all icon buttons; ensure keyboard navigation works in all modals

#### 8. Drug Interaction Coverage Gaps
- **Issue**: Missing ACE-I + K+-sparing diuretic interaction (common hyperkalemia cause in elderly)
- **File**: `src/engine/drugSafety.ts`
- **Recommendation**: Add to `checkDrugInteractions()` database

### Low Priority (Technical Debt)

#### 9. Hardcoded Dates in Tests
- **Files**: Multiple test files use `new Date("2026-03-04T...")`
- **Issue**: Tests become confusing after dates pass
- **Recommendation**: Use `vi.setSystemTime()` or relative dates

#### 10. Inconsistent Error Handling
- **Issue**: Mix of try-catch, `.catch()`, and silent failures across components
- **Recommendation**: Establish consistent error propagation strategy

## Suggested Plugins & MCP Integrations

### MCP Server Integrations

1. **Supabase MCP Server** — Direct database queries and real-time subscriptions from the editor for debugging cloud sync issues
2. **Sentry MCP Server** — Error tracking and monitoring for production crashes (especially the infinite loop issues in commit history)
3. **Upstash MCP Server** — Monitor rate limiting stats and Redis state directly

### Recommended NPM Packages

1. **`react-markdown`** + **`rehype-sanitize`** — Replace `dangerouslySetInnerHTML` in AIClinicalReasoning with safe React component rendering
2. **`@sentry/react`** — Production error monitoring with source maps (hidden source maps already configured)
3. **`web-push`** — Server-side push notifications to replace the setTimeout-based alarm system in the SW (which doesn't survive SW termination)
4. **`idb-keyval`** — Replace raw `localStorage` for patient data with IndexedDB (avoids 5MB quota limit, supports structured data)
5. **`workbox`** — Replace hand-rolled SW caching with battle-tested service worker library

### VSCode Extensions

1. **Tailwind CSS IntelliSense** — Essential for the extensive Tailwind usage
2. **ESLint** — Add `eslint.config.js` with `@typescript-eslint/recommended` and `react-hooks/recommended` rules
3. **Pretty TypeScript Errors** — Better error messages for the complex type system
4. **i18n Ally** — Useful for the Hebrew/English mix in the codebase

### CI/CD Improvements

1. **Add ESLint to CI** — Create `eslint.config.js` and add `npm run lint` step
2. **Lighthouse CI** — Run Lighthouse performance audits on every deploy
3. **Bundle size tracking** — Add `bundlesize` or `size-limit` to track regressions
4. **Dependabot** — Enable for automated security updates
